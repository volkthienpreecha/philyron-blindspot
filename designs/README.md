## Shared generation brief

Generate a polished landscape desktop UI mockup, straight-on and full-screen. Use only the dashboard in the supplied cybersecurity screenshot as the near-1:1 composition reference. Preserve the slim sidebar, narrow toolbar, top-left segmented semicircular gauge, top-right trend chart, bottom-left compact equipment table, and bottom-right context/map panel. Re-theme it as Philyron Blindspot Discovery with Inter and JetBrains Mono, the public brand's ink, blue, and teal palette, and maritime maintenance evidence. Include Report coverage, Sensor evidence, Investigation queue, Selected case, and a Synthetic demo badge. Replace cybersecurity content with candidate unreported equipment issues and related captain logs. Sample chart values, dates, users, and counts are illustrative design content, not results from the backend. Actual implementation must use backend data, correct chart units, and the real brand mark.
